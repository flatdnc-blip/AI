# Shared AI Context

## Purpose

This repository is the shared long-term working memory for Genspark and GPT/Codex.

## Recording standard

- Record confirmed decisions, verified facts and sources, project state, deliverables, handoffs, and open tasks.
- Label assumptions and unverified information clearly.
- Do not store raw chat transcripts unless specifically needed as an evidence attachment.
- Never store credentials, tokens, passwords, or personal data.
