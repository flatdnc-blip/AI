# AI Shared Knowledge Hub

Shared working memory for Genspark, GPT/Codex, and Claude.

Start with `AI_SHARED_KNOWLEDGE/RECENT_CONTEXT.md`, then read the relevant project and handoff records. See `AGENTS.md` for operating rules.

## Quick start

- **GPT/Codex** — At the start of a new conversation, paste the prompt in `PROMPT_FOR_AGENTS.md`.
- **Genspark** — Paste the same prompt when beginning a new session. If GitHub write access is unavailable, draft the content and commit it manually.
- **New AI agents** — Use the same prompt, then add an entry for the agent in the registry in `AGENTS.md`.

## Participating agents

| Agent | Role |

| Genspark | Research and web tasks |
| GPT/Codex | Code generation and analysis |
